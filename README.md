# Поток — автомобили из Китая

Витрина подержанных автомобилей китайского рынка: фотолента, подбор по марке и
модели, карточка с полным набором характеристик. Данные реальные — собраны с
[en.guazi.com](https://en.guazi.com) и лежат в репозитории.

```bash
make prod DOMAIN=cars.example.com ACME_EMAIL=you@example.com
```

Одна команда поднимает на VPS весь стек: API, витрину и TLS. На 443 стоит nginx,
сертификат Let's Encrypt выпускает и продлевает certbot. Альтернатива —
`PROXY=caddy`, тогда сертификатом занимается сам Caddy. Подробности —
[DEPLOY.md](DEPLOY.md).

Посмотреть локально, без домена:

```bash
docker build -f backend/Dockerfile -t cargo-auto-api .
docker run --rm -p 8000:8000 \
  -v "$PWD/data:/app/data:ro" -v "$PWD/web:/app/frontend:ro" \
  cargo-auto-api
```

## Из чего состоит

| Каталог | Что внутри |
|---|---|
| `web/` | витрина: фотолента, подбор, карточка (`index.html`, `app.js`, `style.css`) |
| `backend/` | API на FastAPI поверх каталога |
| `data/cargo-auto.db` | сам каталог: 85 автомобилей, 10 617 характеристик, 2 121 фотография |
| `parser/`, `tools/` | сборщик данных с guazi.com — см. [PARSER.md](PARSER.md) |
| `db/schema.sql` | схема, общая для Postgres и SQLite |
| `docker/` | nginx с ACME и автоперезагрузкой, Caddyfile как альтернатива |

## Каталог

В репозиторий вложен SQLite-файл `data/cargo-auto.db` (2,5 МБ) — сайт работает
из коробки, без отдельной базы. Байты фотографий в нём не лежат: снимки хранятся
в объектном хранилище, а строки несут их URL.

API умеет оба движка, выбор — по `DATABASE_URL`:

```
sqlite:///data/cargo-auto.db              # по умолчанию, файл из репозитория
postgresql://user:pass@host/db            # живая база, которую наполняет парсер
```

SQL написан один раз для обоих: слаги марок и моделей хранятся колонками, а не
вычисляются выражениями, а условия фильтра собираются только для переданных
значений — поэтому нет ни диалектных функций, ни приведений типов.

Пересобрать файл из Postgres: `make sqlite`.

## API

| Эндпоинт | Назначение |
|---|---|
| `GET /api/cars` | лента с фильтрами: марка, модель, кузов, двигатель, цена, год, пробег, поиск, сортировка, постраничность |
| `GET /api/cars/{id}` | карточка: все характеристики и все фотографии с подписями |
| `GET /api/brands` | марки с количеством и ценой «от» |
| `GET /api/models?brand=` | модели, опционально в пределах марки |
| `GET /api/filters` | границы цен, годов и пробега; кузова и типы двигателя с количествами |
| `GET /api/health` | состояние и выбранный движок БД |

## Цены

Источник указывает цены в долларах. Рублёвая цифра — пересчёт по курсу из
`USD_RUB_RATE` в `.env`; при значении `0` витрина показывает исходные доллары.
Курс сам себя не обновляет: это настройка, и API возвращает применённое
значение в каждом ответе, чтобы число не выглядело взявшимся ниоткуда.

## Что в карточке

На страницу объявления guazi.com выводит около полутора сотен характеристик —
VIN, тип кузова, привод, дату первой регистрации, оценку состояния, момент,
расположение цилиндров, оснащение салона. Собраны все: в среднем 125 на
автомобиль. Фотографий 10–36 на машину, по 1280×960, у каждой своя подпись
(«Front Left 45 Deg», «Engine Bay», «Center Console»).

Интерактивная концепция просмотра автомобилей китайского рынка.

## Просмотр

Запустите `python3 -m http.server 8080` в каталоге проекта и откройте http://localhost:8080.

- `index.html` — адаптивный прототип фотоленты.
- `design-system.html` — визуальные токены, компоненты, состояния и правила UX.
- `style.css` — общие стили и CSS-переменные.
- `app.js` — фильтры, избранное на устройстве, клавиатурное управление и диалог стоимости.

Карточки, комплектации и расчёты — демонстрационные, не предложения о продаже. На каждую модель используется одно фото; горизонтальная галерея описана в дизайн-системе как поведение при наличии дополнительных фотографий. Backend, реальный каталог и заявки не подключены.

Фотографии: Wikimedia Commons, см. `assets/credits.json` и `assets/additional-photo-credits.json`. Шрифт Manrope загружается через Google Fonts, при отсутствии сети используется Arial.

## Мобильная версия

Лента занимает доступную высоту окна; проверены размеры 390×844 и 320×667. Фотографии вписаны без обрезки, доступны в полноэкранном диалоге. Компактный подбор открывает панель марки, бюджета с доставкой, двигателя и кузова. Изменения применяются явно; закрытие панели отменяет черновик. На очень низких экранах доступна прокрутка страницы.

## Визуальный подбор

Марки представлены оригинальными логотипами из Wikimedia Commons (`assets/logo-credits.json`). Поиск, переход к моделям, выбор фотокарточки и сброс работают с десятью демонстрационными автомобилями. Дополнительные параметры раскрываются отдельно; нижняя кнопка показывает количество результатов. Закрытие панели отменяет неприменённые изменения. Поколения не показаны: достоверных данных по ним в демокаталоге нет.

Каталог: Zeekr — 4 предложения (001, 007, X), Li Auto — 3 (L6, L7, L9), Xiaomi — 3 (два SU7 и YU7). Модель выбирается только после марки. Цена модели «от» берётся из самого дешёвого предложения этой модели.
